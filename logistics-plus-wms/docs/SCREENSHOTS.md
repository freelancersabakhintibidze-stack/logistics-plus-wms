# UI Screenshots

No screenshot of a live application is included because there is no connected database or deployed staging UI in the delivery environment. This avoids fabricating records or representing a mock screen as a production screenshot.

Capture the following after deploying to a sanitized staging environment:

1. Dashboard with database-derived KPI cards and order status distribution.
2. Product catalog with a known non-sensitive SKU and visible applied filters.
3. Inventory for a multi-warehouse SKU, showing only fields present in the live schema.
4. Order list and detail with sensitive customer information masked.
5. Reports/schema discovery panel and empty/error-state examples.

Use synthetic screenshots only if clearly labeled as design mockups and isolated from the operational system; this package intentionally contains no mock data.
